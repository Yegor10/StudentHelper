# StudentHelper

A bilingual study planner with Google Classroom support in both the Chrome extension and the Python desktop app.

[Set up the Chrome extension](chrome-extension.md){ .md-button .md-button--primary }
[Install the desktop app](installation.md){ .md-button }

</div>

!!! info "Choose your interface"
    The **desktop app** combines the timetable, homework diary, Google Classroom assignments, and Gemini in one installable Windows app. The **Chrome extension** provides the same Classroom assignment workflow directly in Chrome.

<div class="grid cards" markdown>

-   :material-calendar-week:{ .feature-icon } **A plan for every weekday**

    Keep independent Monday-Friday lessons and meeting links in the desktop app. The schedule is saved locally.

-   :material-notebook-edit:{ .feature-icon } **Homework on your calendar**

    In the desktop app, plan homework by date, add text or photos, and keep Gemini explanations with each task.

-   :material-palette:{ .feature-icon } **Make it yours**

    The desktop app supports English and Ukrainian, light/dark/system appearance, and accent colors.

-   :material-shield-lock:{ .feature-icon } **Private by default**

    Timetables are stored locally. Google Classroom and Gemini are contacted only for the features you choose to use.

</div>

## Desktop app, at a glance

| Schedule | Diary | Classroom | Settings |
|:--|:--|:--|:--|
| Five independent weekday plans | Five-day homework calendar | Nearest deadlines first | English or Ukrainian |
| A different first bell each day | Text and image tasks | Attach files, confirm submission | Light, dark, or system |
| Optional browser meeting links | Saved solutions | Gemini explanations | Blue, green, or midnight accent |

!!! tip "Getting started"
    [Install the Windows desktop app](installation.md), configure the Desktop OAuth JSON to connect Classroom, then add a Gemini key if you want AI-powered explanations.
